# Testing

**Date:** 2026-07-12

## Framework
- **Node Test Runner**: Uses the native Node.js test runner (`node --test`).

## Structure
- Tests are located in the `/test/` directory.

## Current Practices
- A `smoke` script (`node scripts/smoke.js`) is provided for basic end-to-end smoke testing.
- A `diagnose` script (`node scripts/diagnose.js`) assists in validating configuration and connectivity.
